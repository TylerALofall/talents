## 8. Placeholders

### 8.1 How Placeholders Work

Placeholders are variables in the prompt that get replaced with real values before sending to Claude.

**Format:** `{{VARIABLE_NAME}}`

**Process:**
1. Script reads the system prompt template
2. Script reads your placeholder values from the request config
3. Script replaces each `{{VARIABLE_NAME}}` with the corresponding value
4. Result is sent to Claude

### 8.2 Built-in Placeholders

| Placeholder | What to Put There | Required |
|-------------|-------------------|----------|
| `{{PROMPT}}` | Your description of the tool you want created | Yes |
| `{{TOOL_BUILDING_GUIDE}}` | Full contents of USER_MANUAL.md | Recommended |
| `{{USER_GUIDE}}` | Full contents of CLAUDE_CODE_INSTRUCTIONS.md | Recommended |

### 8.3 Custom Placeholders

You can add any custom placeholder. Just add it to the `placeholders` object in your request config, then use `{{YOUR_NAME}}` in any text field.

Example:
```json
{
  "placeholders": {
    "PROMPT": "Create a {{FOOD_TYPE}} formatter tool",
    "FOOD_TYPE": "recipe",
    "AUTHOR_NAME": "Tyler Lofall"
  }
}
```

## 12. Error Handling

### 12.1 HTTP Status Codes

| Code | Meaning | Cause | Solution |
|------|---------|-------|----------|
| 200 | Success | Request processed | Parse response normally |
| 400 | Bad Request | Malformed JSON, invalid parameters | Check request format against API docs |
| 401 | Unauthorized | Invalid or missing API key | Verify API key is correct and not expired |
| 403 | Forbidden | Key doesn't have permission | Check API key permissions at console.anthropic.com |
| 429 | Rate Limited | Too many requests | Wait 60 seconds and retry |
| 500 | Server Error | Anthropic's servers had an issue | Wait and retry, not your fault |
| 529 | Overloaded | Anthropic's servers are busy | Wait 30-60 seconds and retry |

### 12.2 Error Output Format

When an error occurs, the output file still gets created with this structure:

```json
{
  "success": false,
  "error": "Detailed error message here",
  "status_code": 401,
  "response_text": "Raw response from API (if available)",
  "timestamp_utc": "2025-12-31T10:30:45.123Z"
}
```

### 12.3 Common Errors and Solutions

**Error: "Environment variable not set" or empty API key**
```
Cause: The API key variable is empty or not found
Solution: The API key is embedded in the script. Open anthropic_tool_crafter_01_call.ps1 
and verify line 20 has the correct key.
```

**Error: "Invalid JSON in request file"**
```
Cause: Your request config has a syntax error
Solution: 
1. Check for missing commas between fields
2. Check for trailing commas after last field (not allowed in JSON)
3. Check that all strings are in double quotes
4. Use a JSON validator: https://jsonlint.com/
```

**Error: "model: field required"**
```
Cause: The model field is missing from the request
Solution: Add "use_model": "opus" or "use_model": "sonnet" to your request config
```

**Error: "529 Overloaded"**
```
Cause: Anthropic's servers are at capacity
Solution: Wait 30-60 seconds and try again. This is temporary.
```

**Error: Response is truncated / incomplete**
```
Cause: max_tokens was too low for the generated content
Solution: Increase override_max_tokens in your request config (try 40000)
```

## 13. Troubleshooting

### 13.1 The script won't run at all

**Symptom:** PowerShell shows red error text immediately.

**Check 1:** Are you in the right directory?
```powershell
Get-Location
# Should show your toolbox path
```

**Check 2:** Does the script exist?
```powershell
Test-Path ".\anthropic_tool_crafter\anthropic_tool_crafter-instructions\anthropic_tool_crafter_01_call.ps1"
# Should return True
```

**Check 3:** Is execution policy set?
```powershell
Get-ExecutionPolicy
# Should be RemoteSigned or Unrestricted
# If Restricted, run:
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 13.2 The script runs but API call fails

**Symptom:** Script starts but shows HTTP error.

**Check 1:** Is the API key valid?
- Go to https://console.anthropic.com/
- Check that your key exists and isn't revoked
- Check that your account has credits

**Check 2:** Can you reach the API?
```powershell
Test-NetConnection api.anthropic.com -Port 443
# Should show TcpTestSucceeded: True
```

**Check 3:** Is your request config valid?
```powershell
Get-Content ".cauldron\anthropic_tool_crafter.request.json" | ConvertFrom-Json
# Should parse without error
```

### 13.3 The response is empty or too short

**Symptom:** Output file exists but tool_content is minimal.

**Check 1:** Was thinking enabled?
- Look at the output JSON's `thinking` field
- If empty and you expected thinking, check your config

**Check 2:** Was max_tokens high enough?
- Check `usage.output_tokens` in the output
- If it equals `max_tokens`, the response was truncated
- Increase `override_max_tokens`

**Check 3:** Was the PROMPT placeholder filled in?
- If PROMPT was empty, Claude had nothing to work with
- Check your request config

### 13.4 The generated tool doesn't work

**Symptom:** Claude produced output but it has errors.

**Solution 1:** Re-run with more thinking budget
- Increase `thinking.budget_tokens` to 20000
- Complex tools need more reasoning time

**Solution 2:** Provide more context
- Fill in TOOL_BUILDING_GUIDE with the full USER_MANUAL.md
- Fill in USER_GUIDE with the full CLAUDE_CODE_INSTRUCTIONS.md
- More context = better output

**Solution 3:** Be more specific in PROMPT
- Instead of "create a recipe tool"
- Say "create a recipe tool that reads X format and outputs Y format with Z features"
