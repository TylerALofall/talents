# anthropic-api-call

ABSOLUTE TRUTH. Models do not edit this file.

## Definitions

- **anthropic_api_key**: Environment variable ANTHROPIC_API_KEY containing your Anthropic API key. Never written to disk, only read from environment. Get this from console.anthropic.com under API Keys. Required for all requests.

- **messages**: Array of message objects following Anthropic's Messages API format. Each object has "role" (user or assistant) and "content" (the message text). This is how you build multi-turn conversations. User messages are questions or instructions. Assistant messages are previous responses (for continuing conversations).

- **system_prompt**: Optional top-level instructions that guide Claude's behavior for the entire conversation. Not part of the messages array. Use this to set persona, task parameters, or constraints that apply to all responses. More powerful than putting instructions in the first user message.

- **max_tokens**: Maximum number of tokens Claude can generate in the response. Required by Anthropic API (no default server-side). Tool defaults to 16000 which allows for substantial responses. Extended thinking can consume more tokens. Set higher for complex tasks, lower to control costs.

- **extended_thinking**: Optional feature where Claude shows its reasoning process before answering. Configured via the "thinking" object with type (enabled, disabled, or budget-controlled) and token budget. Useful for complex reasoning, legal analysis, or high-stakes decisions where you want to see the work.

## Requirements

The tool reads a JSON configuration file from .cauldron with the following structure:

**File: .cauldron/anthropic-api-call.request.json**

```json
{
  "model": "claude-opus-4.5-20250514",
  "messages": [
    {
      "role": "user",
      "content": "Your question or instruction here"
    }
  ],
  "system": "Optional system prompt here",
  "max_tokens": 16000,
  "temperature": 1.0,
  "thinking": {
    "type": "enabled",
    "budget_tokens": 10000
  },
  "metadata": {
    "user_id": "your-identifier"
  }
}
```

All fields except "messages" are optional and will use sensible defaults if omitted.

## Outputs

The tool writes a JSON response file to .outbox containing:

**File: .outbox/anthropic-api-call.output.json**

- **content**: Array of content blocks from Claude (text and thinking blocks if extended thinking was used)
- **usage**: Token counts (input_tokens, output_tokens, and if thinking was used: thinking_tokens)
- **stop_reason**: Why generation stopped (end_turn, max_tokens, stop_sequence)
- **model**: Which model was actually used
- **id**: Unique message ID for tracking
- **metadata**: Any metadata you included in the request

This output can be chained to other tools or saved as an example for future reference.
