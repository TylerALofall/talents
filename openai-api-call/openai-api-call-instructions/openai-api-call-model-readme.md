## Definitions
- **stored_prompt**: A reusable prompt template stored in OpenAI Dashboard
- **prompt_id**: Format pmpt_xxxxx - the unique identifier
- **openai_api_key**: Environment variable only, never written to disk

## Requirements
- openai-api-call.request.json in .cauldron
